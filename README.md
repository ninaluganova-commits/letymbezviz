# «Летим без виз» — восстановление проекта

Исходный сайт — https://letim-bez-viz-planner.ninaluganova.chatgpt.site/

Sites подтвердил опубликованную версию 1 и её коммит `e1505bff5f7c6606230e0330925109da03058884`. Получить содержимое коммита и открыть страницу в этой среде не удалось. Этот README фиксирует состояние восстановления. Файлов приложения пока нет.

## Статус функций

- **Восстановлено.** Подтверждены адрес сайта и версия для выгрузки. Рабочие функции пока не восстановлены.
- **Требует проверки после выгрузки.** Оформление и адаптивная вёрстка, сценарии планировщика, способ хранения данных и возможные серверные зависимости. Список конкретных доработок можно составить после просмотра файлов и запуска проекта.

## Что нужно для продолжения

Передайте ZIP исходников или доступный Git-репозиторий с указанным коммитом. Если доступна только выгрузка браузера, для реконструкции понадобятся HTML, CSS, JavaScript и связанные ресурсы. Архив исходников даст возможность проверить серверный код и настройки сборки.

## Как опубликовать после восстановления

Если приложение работает как статический сайт, поместите готовый каталог с `index.html` и ресурсами в корень ветки `main` или в папку `docs/`. В GitHub откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, укажите `main` и нужную папку, затем нажмите **Save**. Для сайта репозитория проверьте, что ресурсы и внутренние ссылки работают по адресу вида `https://<владелец>.github.io/<репозиторий>/`. Если проект требует сборки, публикуйте её результат через **GitHub Actions**.

[Инструкция GitHub по выбору источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

Если исходники используют серверные маршруты, базу данных или интеграции Sites, выбор хостинга зависит от этих компонентов. GitHub Pages может разместить статический интерфейс, а серверную часть потребуется развернуть отдельно или перенести вместе с интерфейсом на хостинг с поддержкой нужной среды исполнения.
